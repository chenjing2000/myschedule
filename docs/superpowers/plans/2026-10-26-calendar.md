# Compact Calendar Implementation Plan

> **For agentic workers:** Use superpowers:executing-plans for inline execution. Steps use checkbox syntax.

**Goal:** 实现用户确认的紧凑三级日历。
**Architecture:** MainWindow管理当前层级、浏览年月和十年范围；CalendarView继续负责日期数据及事项呈现。保持现有业务服务。
**Tech Stack:** .NET 8 WPF，无新增第三方依赖。
**Spec:** ../specs/2026-10-26-calendar-design.md

## Global Constraints
- 年份1901～2100，保留JSON、农历算法、提醒与日期点击行为。
- 日期/月份/年份滚轮步长为月/年/十年；浏览不改变选择。

## Review Focus
- 十二月/一月跨年以及1901/2100边界。
- 年份滚动保持选择，Esc逐级返回。
- 最小尺寸下六行日期、双行文字和年份圆不裁切。
- 顶部今天与浏览月份分开，跨午夜更新。
- 日程标记、提示和提醒闪烁保留。
