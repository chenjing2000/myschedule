# Event Editing and Recurrence Implementation Plan

> **For agentic workers:** Use superpowers:executing-plans for inline execution.

**Goal:** 实现已确认的紧凑编辑窗与五种周期、新JSON及提醒去重。
**Architecture:** ScheduleItem/ScheduleDate定义数字日期和规则；ScheduleOccurrence集中判断实际发生日期；ScheduleService保存与校验；窗口只协调输入和显示。
**Tech Stack:** .NET 8 WPF / System.Text.Json，无第三方依赖。
**Spec:** ../specs/2026-10-26-event-design.md

## Global Constraints
保留现有用户文件；不兼容旧格式且读取失败禁止写入；月重复含闰月并跳过不存在日期。

## Review Focus
农历二月三十不能当作阳历DateTime；起始日以前不得出现；腊月跨阳历年；跨午夜提醒及同日多事件；读取失败/外部改动不可覆盖。
